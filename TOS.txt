4. Camera Policy

When enabled by a server administrator, G33KY BOT may monitor whether a member's camera is enabled while the member is in a designated voice channel.

The default camera system provides:

* A silent grace period
* A warning/reminder
* A configurable countdown
* Removal from the monitored voice channel if the requirement is not met

The default configuration is a **2-minute silent grace period followed by a 3-minute warning period**, although server administrators may change these settings. 

Members with designated exemption roles may be excluded from camera enforcement. 

G33KY BOT does **not record, save, or transmit camera video to G33KY BOT'S operators** as part of this feature. The Bot uses Discord's voice-state information to determine whether the camera requirement is satisfied.

5. Activity Tracking

When Activity Tracking is enabled, G33KY BOT records limited participation information for members.

By default, a member may be considered active when they:

* Send a message in the server, or
* Spend at least one continuous minute in a voice channel.

The default activity window is **30 days**, and the threshold can be configured by the server administrator. 

G33KY BOT records the **most recent qualifying activity timestamps**, rather than storing a complete history of every message or voice session. 

6. Automated Roles and Restrictions

G33KY BOT may automatically assign or remove server roles based on the configuration established by server administrators.

A server may use those roles to control access to channels or other server features.

G33KY BOT itself does not create or modify Discord channel permission overwrites for the activity system. Any restrictions associated with an inactive role are configured by the server administrator through Discord's normal permission system. 

7. Reactivation

A server may provide inactive members with a self-service reactivation button.

Using the reactivation feature records a new activity timestamp and may restore the member's Active role and remove the Inactive role, depending on server configuration.
